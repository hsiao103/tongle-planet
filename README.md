# 同樂小行星 Tongle Planet

以同樂國小為藍本的 3D 小星球遊戲：校園位在半徑 100 公尺的球形小行星中央，周圍有草原、果樹、沙灘與海。單一 HTML 檔，Three.js r128（執行時由 cdnjs 載入），不需要伺服器。

- 一般版：採集、釣魚、擺設、居民委託、日夜、寫實／動漫線條畫風、手機觸控
- 萬聖節限定版：南瓜、可愛骷髏頭、小蝙蝠、三隻老師變成的校園妖怪
- 單人版／多人版：開場畫面與右上「模式」按鈕可切換；單人版完全不連線、不需登入。
- 多人上線（最多 25 人）：GitHub Pages 版用 Supabase（Google 登入 + Realtime），設定見 `docs/SUPABASE.md`；Claude Artifact 版用 `room`；都沒設定時自動停用，單機照玩

## 快速開始

```bash
bash build.sh        # 需要 node；產生 index.html
# 直接用瀏覽器開啟 index.html 即可遊玩（需要網路載入 three.js）
```

放到 GitHub Pages：Settings → Pages → 選分支根目錄，`index.html` 與 `.nojekyll` 已就緒。多人上線需要先完成 `docs/SUPABASE.md` 的設定並把金鑰填進 `config.js`；沒設定也能單機遊玩。

## 資料夾

- `src/`：原始碼分檔（`part1.html` 為頁面與 CSS；`part*.js` 依 `build.sh` 順序串接）
- `vendor/`：GLTFLoader、SkeletonUtils，以及角色模型資料（`herodata.js`，內含 base64 的 .glb）
- `tests/`：用 Playwright 在無顯示卡環境驗證的腳本（需 `playwright-core`，並把 three r128 的 `three.min.js` 放進 `tests/`；`bash tests/mk.sh` 建立測試頁，`tests/mock.js` 可在本機模擬多人房間）
- `build.sh`：串接並檢查語法

## 多人上線架構

`src/part12.js` 的遠端角色顯示只依賴兩個介面：`presence(patch)` 寫自己的狀態、`peers()` 讀所有人。目前有兩種傳輸：Claude Artifact 的 `room`，以及 Supabase（`sbRoom`，Broadcast 傳位置、Presence 偵測離線）。要改用別的後端，只要再寫一個提供這兩個函式的物件並指派給 `MP.room`。

# 同樂小行星

以「同樂國小 3D 校園」為基底，改成類似《動物之森》的小星球遊戲：校園在一顆半徑 100 公尺的球形小行星正中央，外面是草原、果樹與沙灘，再外面是海。單一 HTML 檔，Three.js r128（執行時由 cdnjs 載入）。

## 重新建置

`bash build.sh`（需 node）→ 產生 `index.html`，並用 `node --check` 檢查語法。

## 架構

- part1.html：頁面、CSS、遊戲介面（HUD、對話、小舖、背包、委託、擺設列）
- part2.js 場景與材質；part2e.js 夜間教室燈光
- part3a.js 校園本體（平面座標建模；已換成 2026-10-21 版同樂 3D 校園：行政大樓、廚房、科任銜接區、停車場、道路與樓梯等；part3b/3c 已併入 part3a，留空）
- **part3z.js 球面化**：載入時把校園「一次烘焙」到球面（CPU，不用任何客製著色器，所以沒有顯示卡相容問題）。方位等距投影，極點在校園中心；長邊先細分到 5 公尺內；同材質同區塊合併成約 450 次繪製。另含星球地形（草地→沙灘→海）、遠方樹／花／石、星空、依本機時間的日夜與天空、動態物件的座標暫換（DYN）。
- part4.js：玩家與球面相機。物理（走路、碰撞、導覽）仍用平面座標；視線方向 fw 在球面切平面上平行傳送。室內自動切成第一人稱。
- part5.js：地點搜尋與 A* 導航（路線箭頭也會彎貼球面）；part7.js：角色、NPC、昇降機
- part8a.js / part8b.js：遊戲系統——物品資料、存檔、小舖、背包、居民對話與委託、果樹／貝殼／昆蟲／釣魚、家具擺設

## 玩法

E 互動、B 背包、Q 委託、WASD 移動、Shift 跑步、空白鍵跳、拖曳轉視角、滾輪縮放（拉到最遠看整顆星球）。進度存在瀏覽器 localStorage（鍵名 tongle_planet_v1），換電腦或清除網站資料就沒有了。

## 已知限制

- 星球半徑只有 100 公尺，高的建築在遠處看會明顯外傾（這是球面的真實效果）。
- 室內走動時，相機在門口附近切換第一／第三人稱，過門瞬間可能穿牆一小段。
- 新放的家具不會進入導覽網格（居民與導航路線不會繞開）。
- 本專案在無顯示卡的模擬環境實測；真實電腦的幀率尚未量測。

## 與同樂 3D 校園的對應

- 地圖（part3a）、人物骨架與手臂（part7）、地點與建築名稱（part4/5：行政大樓、廚房、教學區西／南／東樓、科任及幼兒園區、梅花廣場、集合場、無障礙電梯）皆以該校園版本為準。
- 校園版的像素風、動漫線稿（後處理著色器）、平面模式、WebXR 沒有帶入：小行星為了避免顯示卡相容問題，只用內建材質做「動漫線條」切換。

## 萬聖節限定版（v15）
- 右上「版本：一般／萬聖節」開啟版本選單，可切換一般版與萬聖節限定版（教師節版為預留位置，尚未開放）。選擇會存在存檔裡（edition、hw）。
- 程式集中在 `part11.js`；與既有系統的接點只有：part8a（物品、存檔欄位、面板清單）、part8b（findInteract／gameTick／gameMini／開場各一行呼叫）、part3z（天空與半球光的紫色色調）、part1.html（按鈕與兩個面板）。
- 內容：小南瓜 14 顆、可愛骷髏糖 6 個（可撿，南瓜 4 分鐘、骷髏 7 分鐘再生）、小蝙蝠 10 隻（繞著玩家飛）、三隻妖怪（碎碎念：1忠；水龍頭：廚房；愛考試：2忠），每隻兩題小挑戰，答對得糖果 ×5＋同樂幣 80，三隻全清再得骷髏糖、小南瓜 ×3、同樂幣 200。
- 妖怪題目與位置在 `HWMON`（part11.js）。要換教室，改 `room` 為目的地清單中的教室名稱即可。
- 只用內建材質與幾何，不使用自訂著色器。

## 多人上線（v16，最多 25 人）
- `part12.js`：用 Artifact 的 `room` 功能（發布時宣告 `capabilities: {room: {}}`）。每人約每 0.15 秒更新自己的 presence（x、y、z、朝向、速度、是否在空中、角色、暱稱），其他人用補間顯示成角色；離開的人自動移除。
- 沒有連線能力時（單機開檔、未受邀者）模組不作用，照常單人玩。
- 上限 `MP.max = 25`；超過 90 公尺不顯示、60 公尺外不更新動畫、名牌 40 公尺內才顯示。
- 暱稱存在 `tongle_nick`，在「版本」選單裡修改，最多 8 字，收到的暱稱會再清除控制字元。
- 目前只同步「看見彼此」；背包、錢幣、萬聖節進度仍各自存在自己的瀏覽器。
- 測試：`t/mock.js` 是用 BroadcastChannel 模擬的 room，可在本機多開分頁測試。


## 線上名單與聊天（多人版）
- 點 HUD 的「線上 N」看名單，可「到他身邊」傳送、對個別玩家「靜音」。
- 點「聊天」（或按 Enter）開啟全頻道聊天，訊息同時以氣泡顯示在角色頭上；每句最多 60 字、每 1.5 秒一句。
- 內建過濾：控制字元、連結、信箱、長數字（電話）、重複字、常見辱罵字；靜音只在本次連線有效，聊天紀錄不保存。
- 聊天走 Supabase Broadcast 的 `c` 事件，不需要額外設定；Claude 內的預覽版只有名單，沒有聊天。
- 人多時可把 `config.js` 的 `sendMs` 調大（例如 400）以降低流量。
